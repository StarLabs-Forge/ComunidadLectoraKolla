# Kolla --- Actualización de Identidad Visual

## 1. Concepto visual

**Kolla** es una plataforma de lectura, escritura y comunidad.

La nueva dirección visual busca una identidad:

-   Cálida
-   Cultural
-   Editorial
-   Moderna
-   Inclusiva
-   Equilibrada
-   Agradable a la vista

La identidad debe funcionar tanto para lectores como para lectoras,
evitando una estética excesivamente femenina o masculina.

### Concepto principal

> **Terracota Editorial**

La idea combina la calidez humana del terracota con tonos neutros, azul
profundo y verde suave para crear una identidad reconocible y versátil.

# 3. Principios de uso del color

### Regla 60 / 30 / 10

-   **60%** --- Fondos neutros: `#F8F3EE` y `#FFFFFF`
-   **30%** --- Identidad: `#A85F55`, `#264653`, `#C98A7D`
-   **10%** --- Acentos: `#D9A441`, `#4F8068`, `#527A9E`

El objetivo es evitar interfaces completamente saturadas.

El terracota representa la personalidad de Kolla, pero **no debe dominar
toda la pantalla**.

# 8. Cards

Las cards deben sentirse editoriales y suaves.

### Características

-   Background: `#FFFFFF`
-   Border: `#E8DED8`
-   Radius: 14--18px
-   Shadow: muy ligera
-   Imagen con radius 10--14px
-   Espaciado interno generoso

Evitar:

-   Shadows demasiado fuertes
-   Borders negros
-   Cards excesivamente compactas
-   Gradientes saturados

# 11. Imágenes

La fotografía/ilustración debe mantener una dirección visual:

-   Paisajes andinos
-   Montañas
-   Arquitectura local
-   Bibliotecas
-   Personas leyendo
-   Personas escribiendo
-   Caminos y viajes
-   Naturaleza
-   Escenas cotidianas
-   Ilustraciones editoriales

### Tratamiento

Preferir:

-   Luz cálida
-   Contraste moderado
-   Tonos tierra
-   Azul profundo
-   Atardeceres
-   Texturas naturales

Evitar:

-   Stock fotográfico excesivamente corporativo
-   Colores neón
-   Imágenes demasiado artificiales
-   Saturación extrema

------------------------------------------------------------------------

# 15. Sombras

Las sombras deben ser sutiles.

``` css
box-shadow:
  0 4px 18px rgba(41, 40, 42, 0.06);
```

Para elementos elevados:

``` css
box-shadow:
  0 10px 30px rgba(41, 40, 42, 0.08);
```

La interfaz debe sentirse ligera, no como un dashboard administrativo.

# 19. Principio de inclusión visual

Kolla **no debe utilizar colores asociados directamente con un género**.

La identidad debe sentirse:

> Para quien lee.

> Para quien escribe.

> Para quien crea.

> Para quien quiere compartir historias.

Por eso el terracota se combina con azul profundo, verde y neutros.

El resultado busca una estética **neutral, cultural y editorial**, sin
perder personalidad.

------------------------------------------------------------------------

# 20. Personalidad de marca

### Kolla debe sentirse:

**Cálida**

No fría ni corporativa.

**Humana**

Las personas y sus historias están al centro.

**Cultural**

Con identidad regional sin caer en clichés.

**Creativa**

Debe invitar a escribir y explorar.

**Moderna**

La estética editorial no significa que la interfaz deba verse antigua.

**Inclusiva**

La identidad visual debe funcionar para diferentes edades, géneros y
gustos literarios.

# 22. Resumen de actualización

### Antes

Paletas independientes:

-   Terracota
-   Azul
-   Naturaleza
-   Creativa

### Nueva dirección

**Una identidad central: Terracota Editorial**

Con soporte de:

-   Terracota profundo
-   Terracota suave
-   Azul profundo
-   Ocre
-   Verde
-   Marfil
-   Neutros cálidos

Esto permite que Kolla tenga **una identidad única y reconocible**,
mientras que géneros, contenidos y estados pueden utilizar colores
secundarios.

------------------------------------------------------------------------

## Frase visual

> **Kolla --- Historias que nos conectan.**

La interfaz debe sentirse como entrar a una buena biblioteca: **cálida,
tranquila, interesante y con ganas de quedarse un rato.**
